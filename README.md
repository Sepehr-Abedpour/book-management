# سیستم مدیریت کتاب

یک پروژه ساده و کاربردی با زبان **Python** برای مدیریت مجموعه‌ای از کتاب‌ها.

در این پروژه می‌توان کتاب‌های موجود را مشاهده کرد، کتاب جدید اضافه کرد و کتاب‌های موجود را حذف کرد.

# امکانات

* مشاهده لیست کتاب‌ها
* اضافه کردن کتاب جدید
* حذف کتاب
* مشاهده و مدیریت کتاب‌های موجود
* رابط کاربری ساده در محیط خط فرمان (Terminal)
* 
# تکنولوژی‌های استفاده شده

* Python
* List
* Dictionary
* Function
* Conditional Statements
* File Handling

# نحوه اجرا

ابتدا Python را روی سیستم خود نصب کنید.

سپس فایل زیر را اجرا کنید:

```bash
python book-management.py
```

# نحوه استفاده

بعد از اجرای برنامه، منوی اصلی نمایش داده می‌شود و می‌توانید با انتخاب گزینه‌های مختلف، کتاب‌های خود را مدیریت کنید.

برای مثال:

```text
1. نمایش کتاب‌ها
2. اضافه کردن کتاب
3. حذف کتاب
4. خروج
```

با انتخاب هر گزینه، عملیات مربوط به آن انجام می‌شود.

# هدف پروژه
